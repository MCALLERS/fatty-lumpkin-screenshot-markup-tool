# Contributing

Please open an issue before a substantial feature change. Small fixes and documentation improvements are welcome. Keep the everyday workflow short: capture, annotate, done, paste.

Follow docs/BUILDING.md. Use synthetic fixtures and temporary libraries. Preserve original screenshots, original export dimensions, idempotent save retries, and confirmation only after a successful save/clipboard acknowledgement. Keep network inputs validated and retain the native PencilKit canvas.

Never commit screenshots from a real desktop, pairing tokens, developer certificates, provisioning profiles, device identifiers, build logs, or personal paths. Include relevant test results in pull requests. Contributions are provided under the repository’s MIT license.
