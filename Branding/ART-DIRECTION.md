# Ludwig's Annotated Screenshots artwork

The current app mark is the approved website favicon: screenshot crop corners, a hand-drawn annotation ring, and a pencil. Ink `#202824`, paper `#f6f2e9`, and pencil `#df725b` match the vector source. No paid generation is used for these exports.

- `app-mark.svg`: canonical vector, copied from the approved website favicon.
- `scripts/render-brand-icon.swift`: deterministic CoreGraphics rendering of the vector paths in sRGB.
- `AppIcon-1024.png`: opaque iPad/App Store icon; the platform applies its own rounded mask.
- `AppIcon-mac-1024.png`: Mac icon with transparent outer corners.
- `AppIcon.icns`: Mac icon sizes generated by `scripts/build-icons.sh`.
- `BrandMark.png`: 512px mark used in the Mac welcome screen, native iPad BrandMark image set, and Safari companion.

Run `scripts/build-icons.sh` to regenerate all exports. The script uses local Swift, sips, and iconutil; it makes no network or media-generation calls.
